  <h1>COVID-19 Data Analysis with Python</h1>

  <p>This project provides insights into global COVID-19 data using Python libraries like <strong>Pandas</strong>, <strong>Matplotlib</strong>, and <strong>Seaborn</strong>.</p>

  <h2>📌 Features</h2>
  <ul>
    <li>Data Collection & Cleaning</li>
    <li>Exploratory Data Analysis</li>
    <li>Trend Visualization</li>
    <li>Vaccination vs Case Trends</li>
  </ul>

  <h2>📁 Dataset</h2>
  <p>Dataset used: <a href="https://ourworldindata.org/covid-deaths" target="_blank">Our World in Data COVID-19</a></p>

  <h2>🛠️ Tools & Libraries</h2>
  <ul>
    <li>Python</li>
    <li>Pandas</li>
    <li>Matplotlib & Seaborn</li>
    <li>Jupyter Notebook</li>
  </ul>

  <h2>🚀 How to Run</h2>
  <ol>
    <li>Clone the repository</li>
    <li>Install dependencies: <code>pip install -r requirements.txt</code></li>
    <li>Run the Jupyter notebook</li>
  </ol>

  <h2>📊 Sample Output</h2>
  <p>Graphs showing daily cases, deaths, and vaccine coverage across countries.</p>
